## 🚀 Featured Projects

### 🎬 ClipForge

**AI-powered video clipping and captioning tool**

ClipForge is a local AI video-processing application designed to help automatically analyze video content, identify useful moments, generate captions, and produce clips.

The project has separate implementations for Windows and Linux.

**Technologies & concepts:**
- Python
- FFmpeg
- Whisper / speech-to-text
- Ollama / local LLMs
- AI-assisted video analysis
- Automatic caption generation
- Scene detection
- Video processing
- CLI tooling
- Caching and resumable processing
- Linux & Windows integration

**Repositories:**
- [ClipForge Windows](https://github.com/Intzevidis7/ClipForge-Windows)
- [ClipForge Linux](https://github.com/Intzevidis7/ClipForge-Linux)
